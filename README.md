# ジーズ課題提出用タスク管理

## 課題内容
HTML・CSS・JavaScript・jQueryで作った、タスク管理アプリです。
ジーズの課題は毎週1週間なので、あえて期限や工数の欄は削除しました。

## できること
- タスクを追加する
- タスクの名前や説明を編集する
- タスクを削除する
- 「これから」「進行中」「完了」の列を移動する
- タスクをブラウザに保存する

## 使い方
1. `index.html`をブラウザで開きます。
2. タスク名と説明を入力し、「タスクを追加」を押します。
3. 「次へ」「戻す」でタスクを移動します。
4. 「編集」「削除」でタスクを管理します。

## 工夫した点・こだわった点
- なるべくユーザー側が直感で使いやすいと感じるデザインにしました。
- タスクと説明で、何をしなければいけないのか、向き合えるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- ドラック&ドロップは調べたところ思っていたより実装が難しそうで諦めました。
- 今回は時間がなくてAIに頼る時間が多かった点が悔やまれます。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- 普段はAsanaを使っていますが、タスクブレイクダウン前の構想段階で簡単にメモするアプリが欲しくて作りました。
- タスクは`localStorage`に保存されます。同じブラウザ・同じ端末で開くと、保存したタスクが表示されると思います...多分。
